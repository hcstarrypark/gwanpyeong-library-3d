# 관평도서관 3D

대전 유성구 **관평도서관**을 웹 브라우저 속 3D 공간으로 옮긴 프로젝트입니다. 건물 밖에서 문을 열고 들어가, 서가의 책을 꺼내 읽고, 의자에 앉고, DVD를 보고, 사무실 컴퓨터로 직접 책을 쓸 수 있어요.

Three.js(r128) 하나로 만들었고, 빌드 과정 없이 HTML·JavaScript 파일만으로 돌아갑니다.

**바로 플레이하기: <https://hcstarrypark.github.io/gwanpyeong-library-3d/>**

## 실행하기

책 데이터와 영상이 별도 파일이라, 폴더를 로컬 웹 서버로 여는 것이 가장 확실합니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 <http://localhost:8000> 을 엽니다.

## 조작법

| 키 | 동작 |
| --- | --- |
| W A S D | 걷기 (Shift: 빠르게) |
| 마우스 | 둘러보기 (화면을 클릭하면 시점 고정) |
| Space | 점프 · 사다리에서 뛰어내리기 |
| 좌클릭 | 책 펼치기, 의자에 앉기, 문·도어록·PC·TV 사용 |
| ← → | 책장 넘기기 (Esc: 덮기) |
| 우클릭 | 책·DVD 들기 (R: 읽기, Q: 제자리에 꽂기) |
| E | 문 열기 |
| N | 다른 방문자에게 보일 내 이름 바꾸기 |
| M | 내 모습(블록 아바타) 무작위로 바꾸기 |
| H | 조작법 보기 |

## 함께 둘러보기 (멀티플레이)

같은 주소로 들어온 사람끼리 서로의 블록 아바타와 이름표가 실시간으로 보여요. 오른쪽 위에 지금 함께 있는 인원이 나와요.

- 걷기, 앉기, 문 열기(손 뻗기), 책 집기·꽂기, 책 들고 다니기, 펼쳐 읽기 동작이 다른 사람에게도 보여요.
- 누가 입구 문이나 사무실·수유실 문을 열면 모두의 화면에서 같이 열려요.
- 아바타 모습(머리 모양·머리색·옷·무늬·재킷)은 처음에 무작위로 정해지고, M 키로 바꿀 수 있어요.

- 서버 없이 브라우저끼리 직접 연결해요(WebRTC, [Trystero](https://github.com/dmotz/trystero)). 처음 만날 때만 공개 Nostr 릴레이를 거쳐 서로를 찾아요.
- 주고받는 정보는 위치·방향·동작, 들고 있는 책 색, 이름과 아바타 모습뿐이에요.
- 회사·학교 네트워크처럼 연결이 막힌 곳에서는 혼자 둘러보기로 동작해요.

## 둘러볼 곳

- **건물 밖**: 주황색 외벽과 파란 간판 입구, 이용 안내판. 문 앞에서 E를 누르면 들어가요.
- **로비**: 도서 검색대, 책 소독기, 반납함, 사무실과 수유실 문.
- **사무실** (도어록 비밀번호가 있어요)
  - 책 쓰기 PC: 원고를 쓰고 완료를 누르면 서가에 꽂혀요.
  - 실시간 CCTV 화면 4개, 실제 시간을 가리키는 벽시계.
- **수유실**: 수유 의자, 기저귀 교환대, 아기 침대.
- **어린이자료실**
  - 서가: 장르별 서가와 벽 서가의 책 4만여 권을 모두 꺼내 읽을 수 있어요. 높은 칸은 이동식 사다리로 올라가요.
  - 쉬는 곳: 둥근 벤치 서가, 꽃 탁자, 검색 PC.
  - 잡지·신문·만화 진열대.
- **DVD 영상 코너**: 레이싱 단편 애니메이션 3편과 실사풍 레이싱 영상 1편. DVD를 집어 플레이어에 넣으면 TV에서 재생돼요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 3D 장면, 조작, 책 읽기 화면, 영상 코너 |
| `books.js`, `books-more.js`, `books-long.js` | 직접 쓴 책 42권 |
| `books-extra.js` | 위 책들에 덧붙인 원고 |
| `bookgen.js` | 서가의 책 내용을 만들어 내는 생성기 |
| `media/` | 레이싱 영상(`gt-rain.mp4`)과 표지 |

## 참고

- 사무실에서 쓴 책은 그 브라우저의 localStorage에만 저장돼요.
- 도서관 안의 신문·잡지 기사와 책 내용은 모두 지어낸 이야기예요.
- `media/gt-rain.mp4`는 AI로 생성한 영상입니다.
